HMS CORS — real browser client test

This file must NOT be opened from localhost:8080 or as a bare file:// URL — both defeat the point. Serve it from a different port so the browser treats it as a genuinely different origin, e.g. from this folder: 
python -m http.server 5500
then open http://localhost:5500/cors-browser-test.html. This is the same demonstration described in HMS v4's User Story 1.2/3.2 (docs/v4/README-V4.MD) — Postman itself doesn't enforce CORS (see the companion postman/HMS-CORS-CSRF-Demo.postman_collection.json for what Postman can verify instead: the server's own header decision). Only a real browser page making a real cross-origin request proves the enforcement side.
